## DAILY-NEWS-AGENT

I am attempting a solo project to make an agent that sends news updates
in emails to users. This is a personal project to understand how agents work.

Through this project, I hope to walk myself through the code and come up with my
own ideas on how to improve the different features while also doing research into
how to improve the quality of responses.

I am also hoping to expand my scope of news outlets so that I am able to get
a wide variety of new sources.
